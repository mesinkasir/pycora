## Pycora Medusa Starter Template - Ready to Use

This starter template includes 3 example articles, about page, and basic configuration. Just clone and run.

**What's Included:**

1. Example article about installation
2. Example article how to create post
3. Example article optimization tips
4. About page ready to edit
5. config.yaml already configured

**How to Use:**

```bash
git clone https://github.com/mesinkasir/pycora
cd pycora
python install.py
python ssg.py
python dev.py
```
Open localhost:8000, see the result. Edit content in content/ folder, rebuild, deploy.

Ready to rock! 🚀
